# Design reference

`reference.jpg` is the target the desk's graphics are compared against
(GFX-094 onward): a mockup generated with OpenAI `gpt-image-2` from a
description of PandaGen's own identity -- the navy surfaces, the mint
accent, the panda wallpaper, cards with header chips, the bottom dock --
so it is reachable with the renderer the desk has. Screenshots from
`cargo xtask qemu-script` are compared with it after each graphics phase.

`dock_concept.jpg` (GFX-114) is the concept for the liquid-glass dock,
generated the same way: a floating capsule of frosted, refracting glass,
the hovered tile large on a glass puck with its name over it, light bars
under running apps, and an Apps button past a divider.
