# PandaGen: Top 5 Next Features/Fixes/Enhancements

Saved list of the highest-impact next steps:

1) **Multi-core (SMP) support** — in progress: Phase 254 brings all CPUs online (spinlock, CPU registry, `cpus`), Phase 255 adds the LAPIC, wake IPIs, and a job queue (`smp run <n>`), Phase 256 splits the desktop present across CPUs (3.2x faster), Phase 261 gives every AP a calibrated 100 Hz LAPIC timer, Phase 262 installs per-CPU GDT/TSS with a double-fault stack and exception diagnostics (`fault pf|ud|de`), Phase 263 lets idle APs poll kernel tasks under a kernel lock (`smp poll`, `smp diag`); next is true parallel task execution (per-task locking instead of one kernel lock).
2) **Persistent bare-metal storage** — done (Phases 252-253): virtio-blk over PCI, disks are mounted across reboots.
3) **Graphics/UI framework beyond text mode** — done (Phases 213-251, see `docs/path_to_graphics.md`): rasterizer, compositor, graphical shell with launcher, palette, editor, notifications, and parallel present.
4) **Advanced network protocols + hardened remote IPC** — in progress: Phase 257 brings up virtio-net on bare metal with ARP/IPv4/ICMP (`net ping`), Phase 258 adds UDP with a host-reachable echo port, Phase 259 serves `remote_ipc` calls over UDP (`cargo xtask remote cpus`) with a read-only allowlist, Phase 260 signs every call with HMAC-SHA256 over a shared token (`remote_token=` on the command line), Phase 267 drops replayed datagrams (256-message id window), Phase 268 obtains the address by DHCP at boot; next are lease renewal and TCP.
5) **Formal verification of critical paths** — in progress: Phase 264 adds a model-based checker for the capability lifecycle (exhaustive bounded search plus random sequences) that found and fixed capability theft/resurrection on re-grant of a live id, Phase 265 does the same for the scheduler (fixed duplicate exit events, revival of finished tasks by block, and hash-ordered wake-ups), Phase 266 for IPC channel access (closed two fail-open paths: revoke-to-open and unchecked anonymous traffic); next are the EDF policy and message-budget models.
